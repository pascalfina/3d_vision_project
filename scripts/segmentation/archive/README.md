# Archived Segmentation Helpers

This folder contains older builders and selection files that are no longer part of the
current main workflow.

Typical examples:

- old mixed-root / pilot-root builders
- GT-to-pred bootstrapping helpers
- one-off selection JSON files used for earlier object-level experiments

These files are kept for reference and reproducibility only.

For the current pipeline, use:

- `scripts/segmentation/pipeline/`
- `scripts/segmentation/validation/`
- `scripts/segmentation/visualization/`
- `scripts/workflows/run_scene_profile.sh`
